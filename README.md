# Nepal TopUp Center

Responsive Free Fire top-up front-end template with eSewa QR modal.

## Add your eSewa QR
1. Use a QR for your own eSewa account that you are authorized to receive payments into.
2. Save the image as `your-esewa-qr.png`.
3. Put it in the `assets` folder, so the path is `assets/your-esewa-qr.png`.
4. Test the QR and confirm the payee name shown by the eSewa app before using it.

## Preview
Open `index.html` in a browser, or deploy the project folder to a static host such as Netlify.

## Important
The package prices are examples. The “I have paid” button only displays a pending-verification demo; it does not contact eSewa, verify payment, store orders, or deliver diamonds. For real sales, add a secure backend and an authorized payment-provider integration or manually verify each transaction before fulfilment. Never collect passwords, OTPs, or payment PINs. This is not an official Garena/Free Fire site.
